# Alpha.5 local listing candidate

ForgeRail alpha.5 brings self-contained AGW/WHR workflow guidance, portable recovery, preservation of unrelated staged changes and independent main-package validation.

Two user-operated source-loading trials exercised the baseline behaviors. This does not certify every host, fully isolated execution or every project's legacy integration. Codex is the primary Plugin target; ordinary projects require no Node.js or implicit `.forgerail/` state.

This file aligns the local listing metadata with the release candidate. No Directory submission or publication is approved. See the [release scope and gates](../docs/release-alpha5.md).
