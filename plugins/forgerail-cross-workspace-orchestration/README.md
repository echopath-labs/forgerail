# ForgeRail Cross-Workspace Orchestration

An optional ForgeRail Capability Pack for governing safe parallel work across genuinely independent owner workspaces, repositories, or release identities.

Use it when a master task must assign product owners, dependency waves, single-writer identities, independent approvals, stable handoffs, receipt review, and partial-failure recovery. Production deployment remains separately gated even after release approval. Do not use it for ordinary single-repository or monorepo-folder work.

ForgeRail owns governance and acceptance. RelayPact can optionally transport delegation and returns; EchoPath can optionally provide authorized recovery context. Neither is required. Installation is availability only and performs no task creation, durable write, remote integration, release, or lifecycle mutation.
